# ARNavigation

AR Navigation 팀 프로젝트의 공용 통합 브랜치입니다.

개인 작업은 각자의 이름으로 만든 브랜치에서 진행하고, 검토 후 Pull Request를 통해 `main`에 병합합니다.

## 앱에 적용된 내용

- 문화관 1~5층 지도와 개발용 테스트 지도에서 출발지·목적지를 선택하고 최단 경로를 탐색합니다. 출입구가 여러 개면 짧은 경로의 출입구를 선택합니다.
- 같은 층의 탐색 경로를 실제 바닥 위에 AR 경로선으로 표시합니다. 출발 위치는 사용자가 실제 위치에 맞춰야 합니다.
- 문화관 지도는 센서 자북 기준 반시계 85.5°(방위각 274.5°)로 정렬합니다. 수동 방향 보정과 추가 회전각도 지원합니다.
- AR 녹화 시 지도·층·출발 노드를 선택하고, 녹화 목록에서 재생·삭제할 수 있습니다. 새 녹화에는 지도 정렬 정보도 저장해 재생 시 복원합니다.
- 설치용 디버그 APK: [apk/ARNavigation-debug.apk](apk/ARNavigation-debug.apk). Android 7.0(API 24) 이상 ARCore 지원 실제 기기에서 테스트합니다.

## 사용방법: 경로 지정 및 화면 표시

1. 앱을 실행하고 카메라 권한을 허용합니다.
2. **지도/경로**를 누르고 사용할 지도를 선택합니다.
3. **출발지**와 **목적지**를 선택합니다. 문화관은 같은 층의 지점을 선택하고, **추가 회전각**은 기본값 0°로 둡니다.
4. **길찾기 (A*)**를 눌러 탐색 결과와 출발 진입점을 확인합니다.
5. **이 경로로 AR 미리보기** 또는 **이 경로로 AR 안내**를 눌러 선택한 경로를 AR 화면으로 전달합니다.
6. 결과에 표시된 실제 출발 진입점에 서서 카메라로 주변 바닥을 천천히 비춰 바닥을 인식시킵니다. 문화관은 폰 방위 센서로 지도 방향을 맞춥니다.
7. **길안내 시작**을 누르면 인식된 바닥 위에 경로선이 표시됩니다. 바닥 인식이나 방위 센서가 불안정하면 화면 안내에 따라 안정된 뒤 다시 시도합니다.

## 테스트할 점

- [ ] 문화관 층·출발지·목적지를 바꿔 경로가 정상 표시되는지, 출입구가 여러 개인 호실에서 적절한 출입구가 선택되는지 확인합니다.
- [ ] 실제 출발점에서 바닥을 인식한 뒤 안내를 시작하고, 경로선의 높이와 복도 방향이 맞는지 확인합니다. 이동·제자리 회전 후에도 경로가 바닥에 고정되는지 확인합니다.
- [ ] 같은 출발점에서 폰 방향을 0°·90°·180°로 바꾸고 기울여 다시 시작해도 문화관 경로 방향이 일정한지 확인합니다. 센서가 불안정하면 시작 대기 또는 오류가 표시되는지 확인합니다.
- [ ] 수동 방향 보정과 추가 회전각을 각각 적용해 의도한 방향으로 한 번만 회전하는지 확인합니다.

다층 경로 계산은 지원하지만 층간 AR 보행 안내와 자동 층 인식은 아직 구현X.
