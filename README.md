# ARNavigation

## 현장 테스트 / QA (미완료)

apk 업로드가 안돼서(100mb 초과) 빌드해서 테스트해주세요

- [ ] **안내 거리:** 같은 층의 직선 구간과 좌·우회전 구간을 각각 걸으며 `다음 지점까지`와 `몇 m 앞에서 회전`의 거리가 전진할수록 줄어드는지 확인합니다. 경유점을 약간 옆으로 지나쳐도 숫자가 다시 커지거나 이전 안내에 머무르지 않아야 합니다.
- [ ] **출발점·방향:** 문화관의 실제 출발 진입점에서 바닥을 인식해 시작합니다. 버튼을 누른 직후 조금 이동해도 경로 원점이 버튼을 누른 위치에 유지되는지 확인합니다. 경로선이 복도 진행 방향과 바닥 높이에 맞는지 확인하고, 같은 자리에서 폰을 0°·90°·180°로 돌리거나 기울여 다시 시작해도 경로 방향이 일정한지 확인합니다. 제자리 회전과 보행 중 선이 바닥에 고정되어야 합니다.
- [ ] **복도 경로선 보정:** 양쪽 벽이 보이면 경로선이 가운데로, 한쪽 벽만 안정적으로 보이면 벽 방향으로 먼저 회전하고 그 벽에서 1m 떨어진 쪽으로 천천히 이동하는지 확인합니다. 벽 관측이 끊기거나 코너·계단에 들어가면 선이 갑자기 튀지 않고 지도 경로로 돌아오는지 확인합니다. `도구 → 비전모델 디버그`에서 경계 관측과 각도·X/Z 보정량을 확인합니다.
- [ ] **카메라 시야각:** 현재 SM-S937N에서 ARCore 후면 카메라는 ID 0, 수평 시야각 약 75.7°만 확인됐습니다. 양쪽 벽이 한 화면에 들어오지 않을 때는 기기 방향을 바꿔 확인합니다. 다른 기기에서 초광각 카메라가 ARCore 구성에 포함되면 깊이·추적·녹화 호환성을 확인한 뒤 전환을 검토합니다.
- [ ] **방향 보정:** 센서가 불안정할 때 시작 대기 안내가 나오는지, 수동 방향 보정과 지도 추가 회전각이 각각 한 번만 적용되는지 확인합니다.
- [ ] **다른 층 경로:** 서로 다른 층의 출발지·목적지를 선택해 경로를 생성하고, 계단 이동 후 AR 높이로 다음 층 도착이 추정되면 출구 경로선이 자동으로 표시되는지 확인합니다. 추정이 실패할 때는 `다음 층에서 시작`으로 이어지는지도 확인합니다. 여러 출입구가 있는 호실에서는 선택된 출입구가 실제 동선에 맞는지도 확인합니다.
- [ ] **계단 표시 방식:** `도구 → 계단 표시`를 경로선과 표식으로 번갈아 전환합니다. 경로선 모드에서는 계단 진입부와 계단 위에 선이 보이고, 표식 모드에서는 같은 위치에 `계단 올라감/내려감`이 보이는지 확인합니다. 깊이 보정 전에는 임시 위치, 보정 후에는 계단 표면 위치를 따르고 깊이 정보가 끊겨도 마지막 보정 위치를 유지해야 합니다.
- [ ] **층 추정:** 계단을 오르거나 내려가며 AR 높이 변화와 `이동 중 → 다음 층 도착 가능` 표시가 실제 이동 방향에 맞는지 확인합니다. 폰만 잠깐 올리거나 내렸을 때 다른 층으로 단정하지 않아야 합니다. 도착 표시는 추정이므로 출구에서 실제 층을 확인합니다.
- [ ] **비전모델 디버그:** `도구 → 비전모델 디버그 켜기`가 보이고, 계단을 비출 때 모델 점수·유효 깊이 점 수·임시선/보정선 상태가 갱신되는지 확인합니다.
- [ ] **벽·바닥 경계 표시:** `도구 → 벽·바닥 경계 보기`를 켜고 벽과 바닥이 만나는 곳을 비춥니다. 화면의 노란 선이 실제 접합부를 따르고, 인식되지 않는 장면에서는 `미검출`로 바뀌는지 확인합니다. 끄면 노란 선과 표시가 사라져야 합니다.
- [ ] **AR 녹화·재생:** 출발 지점을 지정해 녹화를 시작·종료한 뒤 목록에 파일이 저장되는지 확인합니다. 재생 중 같은 지도 방향과 경로가 복원되는지, 재생 종료 후 실시간 카메라와 녹화 기능으로 돌아오는지 확인합니다.
- [ ] **각도 실험:** 녹화가 저장된 휴대폰에서 `도구 → 계단 A→B 실험 영상 시작`을 누릅니다. 하단 슬라이더나 숫자 입력으로 72°·85.5° 등을 바꿀 때 재생을 다시 시작하지 않아도 경로선 방향이 즉시 바뀌는지 확인합니다. 이 도구는 해당 녹화에서 비전 경로 보정을 잠시 제외하고 각도만 비교합니다.
- [ ] **반복 재생:** 같은 계단 A→B 영상을 두 번 재생하고 같은 장면에서 경로선의 바닥 위치·방향·높이가 일치하는지 확인합니다. 안내가 시작되는 시각은 달라도 경로 원점은 같아야 합니다.

## 앱에 적용된 내용

- 문화관 1~5층 지도와 개발용 테스트 지도에서 출발지·목적지를 선택하고 최단 경로를 탐색합니다. 출입구가 여러 개면 짧은 경로의 출입구를 선택합니다.
- 탐색 경로를 층별로 실제 바닥 위에 AR 경로선으로 표시합니다. 출발 위치는 사용자가 실제 위치에 맞춰야 합니다. 길안내 시작 요청을 처리한 첫 추적 위치를 앵커로 고정해 방향·바닥 인식 대기 중 이동해도 경로 원점이 따라가지 않습니다.
- 계단 안내는 경로선과 올라감/내려감 표식 중 선택할 수 있습니다. ARCore 카메라 높이 변화로 다음 층 도착을 추정하며, 층고를 모르는 문화관은 층간 높이 3.3m를 가정합니다. 높이 변화가 확인되면 다음 층 경로를 자동으로 시작하며 실제 층은 출구에서 직접 확인합니다.
- 복도에서는 비전모델이 벽·바닥 경계를 AR 바닥 평면에 투영합니다. 안정적인 벽 방향으로 경로선을 먼저 회전시키고, 양쪽 벽이 보이면 가운데로, 한쪽 벽만 보이면 카메라가 있는 통로 쪽으로 벽에서 1m 떨어진 위치로 이동시킵니다. 관측이 끊기거나 경로가 꺾이면 지도 경로로 복귀합니다.
- 문화관 지도는 센서 자북 기준 반시계 70°(방위각 290°)로 정렬합니다. 수동 방향 보정과 추가 회전각도 지원합니다.
- 비전모델이 인식한 벽·바닥 접합부는 AR 화면에 노란 선으로 표시합니다. `도구 → 벽·바닥 경계 보기`에서 표시를 끌 수 있습니다.
- 기기에 저장된 계단 A→B AR 녹화는 `도구 → 계단 A→B 실험 영상 시작`으로 바로 재생할 수 있습니다. 재생 중 화면 아래 숫자 입력이나 슬라이더로 문화관 각도를 실시간 변경하며, 값은 이 실험 재생에만 적용됩니다. 기본 각도는 70°입니다.
- AR 녹화 시 지도·층·출발 노드를 선택하고, 녹화 목록에서 재생·삭제할 수 있습니다. 새 녹화에는 지도 정렬 정보도 저장해 재생 시 복원합니다.
- 설치용 디버그 APK는 로컬 `apk/ARNavigation-debug.apk`에 보관합니다. 100MB를 넘는 빌드 파일은 GitHub에 올리지 않으므로, 다른 환경에서는 `src`에서 디버그 APK를 빌드해야 합니다. 작업본은 기존 설치본과 함께 설치되도록 별도 패키지로 빌드했습니다. Android 7.0(API 24) 이상 ARCore 지원 실제 기기에서 테스트합니다.

## 사용방법: 경로 지정 및 화면 표시

1. 앱을 실행하고 카메라 권한을 허용합니다.
2. **지도/경로**를 누르고 사용할 지도를 선택합니다.
3. **출발지**와 **목적지**를 선택합니다. 다른 층도 선택할 수 있습니다. 문화관 **추가 회전각**은 기본값 0°로 둡니다.
4. **길찾기 (A*)**를 눌러 탐색 결과와 출발 진입점을 확인합니다.
5. **이 경로로 AR 미리보기** 또는 **이 경로로 AR 안내**를 눌러 선택한 경로를 AR 화면으로 전달합니다.
6. 결과에 표시된 실제 출발 진입점에 서서 카메라로 주변 바닥을 천천히 비춰 바닥을 인식시킵니다. 문화관은 폰 방위 센서로 지도 방향을 맞춥니다.
7. **길안내 시작**을 누르면 인식된 바닥 위에 경로선이 표시됩니다. 바닥 인식이나 방위 센서가 불안정하면 화면 안내에 따라 안정된 뒤 다시 시도합니다.

문화관과 개발용 테스트 지도 모두 다른 층의 출발지와 목적지를 선택해 경로를 탐색합니다. 계단 이동 후 AR 높이 변화가 확인되면 다음 층 경로가 자동으로 이어집니다. 높이 추정이 실패하면 출구에서 **다음 층에서 시작**을 눌러 안내를 이어갑니다. 문화관의 계단 연결은 현장 미검증 시연용 후보이므로, 표시된 거리에 계단 이동 거리와 층고는 포함되지 않습니다.

개발용 지도의 3D 계단 좌표는 계단 구간에도 AR 선으로 표시합니다. 문화관에서는 계단을 카메라에 담으면 온디바이스 ML Kit 모델의 `Stairs` 인식과 화면 여러 위치의 ARCore Depth 관측으로 계단 표면 위의 선을 보정합니다. 모델이 계단을 놓치더라도 충분히 뚜렷한 계단형 깊이 윤곽이 있으면 보정합니다. 보정된 선은 계단 안내 중 즉시 표시하고 깊이 정보가 끊겨도 유지합니다. 아직 보정하지 않았다면 지도상의 진입 방향을 2m 연장한 짧은 임시선을 표시합니다. **도구 → 비전모델 디버그 켜기**에서 모델 점수, 유효 깊이 점 수, 현재 선이 임시선인지 깊이 보정선인지 확인할 수 있습니다. 문화관의 전체 계단 형상과 층고는 실측되지 않았으므로 임시선은 실제 계단과 다를 수 있습니다.
