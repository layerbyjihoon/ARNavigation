# 숭실대학교 캠퍼스 AR Navigation 화면정의서

| 항목 | 내용 |
|---|---|
| 문서 상태 | Draft v1.0 |
| 작성일 | 2026-10-28 |
| 대상 플랫폼 | Android 7.0 이상 (API 24+) |
| 기준 해상도 | 360 × 800 dp, 세로 화면 |
| 기준 문서 | `docs/PRD.md` Draft v1.4 |
| 와이어프레임 | [Figma AR Navigation](https://www.figma.com/design/s34GpRyOS7ACmdafUUIFcU/AR_Navigation) |
| 구현 언어 | Java |

## 1. 문서 목적

본 문서는 AR Navigation의 핵심 화면 구조, 표시 정보, 사용자 동작, 상태 변화와 화면 간 이동을 정의한다. 디자인, Android 구현 및 QA의 공통 기준으로 사용한다.

현재 Figma 와이어프레임에 포함된 홈, 건물 검색, 강의실 선택, AR 안내, AR 중 경로 변경 화면을 상세 정의한다. PRD에 정의된 권한, 저신뢰, API 오류와 같은 예외 상황은 별도 화면을 무조건 추가하기보다 해당 화면의 상태 변형으로 정의한다.

## 2. 화면 범위

### 2.1 현재 정의 화면

| 화면 ID | 화면명 | 출시 단계 | 목적 |
|---|---|---|---|
| SCR-001 | 홈 · 2D 캠퍼스 지도 | P0/P2 | 지도에서 현재 위치와 경로를 확인하고 목적지 검색을 시작한다. |
| SCR-002 | 건물 검색 | P0/P2 | 건물명 또는 장소 키워드로 목적 건물을 찾는다. |
| SCR-003 | 강의실 선택 | P1 | 선택한 건물 내부의 강의실 또는 호수를 찾는다. |
| SCR-004 | AR 안내 | P0/P1/P2 | 카메라 위 방향 화살표와 보조 정보로 다음 웨이포인트를 안내한다. |
| SCR-005 | AR 중 경로 변경 | P0/P1/P2 | 현재 안내를 유지한 채 새 목적지를 검색하거나 기존 경로로 돌아간다. |

### 2.2 후속 정의 대상

다음 화면은 PRD 범위에 포함되지만 현재 와이어프레임에는 독립 화면으로 작성되지 않았다. 구현 전에 별도 화면 또는 상태 변형으로 구체화한다.

- 권한 및 준비 화면
- Google 경로 미리보기 화면
- 실내 Natural Landmark 스캔 화면
- 층 전환 화면
- 도착 화면
- ARCore 미지원, 추적 손실, 데이터 없음 등의 제한 모드 화면

## 3. 공통 설계 원칙

### 3.1 레이아웃과 디자인 시스템

- Material 3 컴포넌트와 Android 시스템 패턴을 우선 사용한다.
- 기본 화면은 360 × 800 dp 세로 레이아웃을 기준으로 하되 다양한 Android 화면 크기에 대응한다.
- 시스템 상태 바와 키보드 영역은 실제 단말의 Window Insets와 IME 높이를 따른다.
- 검색창, 버튼 및 목록의 최소 터치 영역은 48 × 48 dp 이상으로 한다.
- 사용자 표시 문자열, 색상과 크기는 Android 리소스로 관리한다.

### 3.2 접근성

- 상태는 색상만으로 구분하지 않고 텍스트와 아이콘을 함께 제공한다.
- 검색 결과의 입력어 강조는 색상과 함께 글자 굵기를 사용한다.
- 아이콘 버튼에는 TalkBack용 `contentDescription`을 제공한다.
- 상태 변화와 도착 정보는 필요한 경우 `accessibilityLiveRegion="polite"`로 알린다.
- AR 화면에서도 텍스트 안내와 2D 지도 대체 경로를 제공한다.

### 3.3 검색 공통 규칙

- 입력값 앞뒤 공백을 제거한 뒤 검색한다.
- 입력 중 디바운스를 적용해 불필요한 연속 요청을 방지한다.
- 결과의 입력 키워드 일치 부분은 강조 표시한다.
- 지원 건물 및 강의실 여부와 안내 가능 상태를 결과에 함께 표시한다.
- 검색 결과가 없으면 빈 목록 대신 원인과 다른 검색어 입력 안내를 표시한다.
- 네트워크 또는 API 오류가 발생하면 입력값을 보존하고 재시도 동작을 제공한다.

### 3.4 안내 공통 규칙

- 다음 행동, 남은 거리, 목적지, 위치 신뢰도를 사용자가 동시에 확인할 수 있어야 한다.
- 위치 또는 방향 신뢰도가 기준 미만이면 AR 화살표를 숨긴다.
- 안내 종료 또는 경로 취소 시 카메라, 위치, 방향 센서와 AR 세션을 해제한다.
- 목적지 변경이 완료되기 전까지 기존 경로를 유지한다.

## 4. 화면 흐름

```text
앱 실행
  ↓
SCR-001 홈 · 2D 캠퍼스 지도
  └─ 검색창 선택 → SCR-002 건물 검색
                         ├─ 건물 목적지 선택 → 경로 생성/미리보기 → SCR-004 AR 안내
                         └─ 강의실 지원 건물 선택 → SCR-003 강의실 선택
                                                          └─ 강의실 선택 → 경로 생성/미리보기 → SCR-004 AR 안내

SCR-004 AR 안내
  ├─ 검색 → SCR-005 AR 중 경로 변경
  │            ├─ 새 목적지 확정 → 새 경로 계산 → SCR-004 AR 안내
  │            └─ 변경하지 않고 돌아가기 → 기존 경로 유지 → SCR-004 AR 안내
  ├─ 경로 취소 → SCR-001 홈 · 2D 캠퍼스 지도
  └─ 도착 → 도착 상태/화면
```

## 5. SCR-001 홈 · 2D 캠퍼스 지도

### 5.1 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-001 |
| 진입 조건 | 앱 실행 및 초기 준비 완료, AR 화면에서 경로 취소 또는 2D 지도 보기 선택 |
| 주요 목적 | 캠퍼스 지도와 현재 위치를 확인하고 목적지 검색을 시작한다. |
| 종료 조건 | 검색 화면 진입, AR 안내 진입 또는 앱 종료 |
| 관련 요구사항 | FR-001, FR-100, FR-101, FR-103, FR-104, FR-501, FR-503 |

### 5.2 화면 구성

| UI ID | 요소 | 위치 | 표시 내용 | 동작 |
|---|---|---|---|---|
| `home_map` | 2D 캠퍼스 지도 | 전체 배경 | 캠퍼스 건물, 보행로, 현재 경로 | 드래그와 핀치로 지도 이동 및 확대/축소 |
| `home_search_bar` | 검색창 | 상단 | `건물 또는 장소 검색` | 선택 시 SCR-002로 이동하고 키보드 표시 |
| `home_current_location` | 현재 위치 마커 | 지도 위 | 위치 점과 정확도 반경 | 위치 갱신 시 지도 위 위치 갱신 |
| `home_route_polyline` | 경로선 | 지도 위 | 선택된 Google 또는 자체 경로 | 활성 경로가 있을 때만 표시 |
| `home_location_button` | 현재 위치 버튼 | 하단 좌측 | `현재 위치` | 현재 위치 중심으로 지도 이동 |
| `home_destination_card` | 목적지/경로 카드 | 하단 | 목적지, 거리, 예상 시간, 주요 동작 | 목적지 선택 또는 경로 생성 후 표시 |

### 5.3 주요 동작

1. 화면 진입 시 위치 권한 상태를 확인한다.
2. 권한이 있으면 현재 위치를 요청하고 지도 중심과 마커를 갱신한다.
3. 활성 경로가 있으면 경로선, 남은 거리와 예상 시간을 표시한다.
4. 사용자가 검색창을 선택하면 SCR-002로 이동한다.

### 5.4 상태 정의

| 상태 | 화면 동작 |
|---|---|
| 초기 로딩 | 지도 영역에 로딩 상태를 표시하고 검색창은 사용할 수 있게 유지한다. |
| 위치 확인 중 | 현재 위치 버튼에 진행 상태를 표시한다. |
| 위치 권한 거부 | 현재 위치를 숨기고 출발 지점 수동 선택 및 설정 이동을 제공한다. |
| 저신뢰 위치 | 정확도 경고와 정확도 반경을 표시하며 AR 시작을 제한한다. |
| 경로 없음 | 경로선과 목적지 카드를 숨긴다. |
| 경로 있음 | 경로선, 목적지, 거리, 예상 시간을 표시한다. |
| 지도/API 오류 | 오류 원인, 재시도 및 가능한 경우 외부 Google Maps 이동을 제공한다. |

### 5.5 수용 기준

- 화면 상단 검색창과 2D 캠퍼스 지도가 동시에 표시된다.
- 위치 권한 허용 시 현재 위치와 정확도 상태가 갱신된다.
- 활성 경로가 있으면 경로선, 거리와 예상 시간이 표시된다.
- 권한 또는 지도 오류로 앱이 종료되지 않으며 복구 동작이 제공된다.

## 6. SCR-002 건물 검색

### 6.1 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-002 |
| 진입 조건 | SCR-001의 검색창 선택, AR 경로 변경에서 건물 검색 선택 |
| 주요 목적 | 건물명 또는 장소 키워드로 목적지를 검색한다. |
| 종료 조건 | 건물 선택, 뒤로 가기 또는 검색 취소 |
| 관련 요구사항 | FR-001, FR-003, FR-102, FR-107 |

### 6.2 화면 구성

| UI ID | 요소 | 위치 | 표시 내용 | 동작 |
|---|---|---|---|---|
| `building_search_back` | 뒤로 가기 | 상단 좌측 | 뒤로가기 아이콘 | 이전 화면으로 복귀 |
| `building_search_input` | 검색 입력창 | 상단 | 입력값 예: `정보` | 입력 변경 시 추천 검색 요청 |
| `building_search_progress` | 검색 진행 표시 | 검색창 주변 | 작은 진행 표시 | 검색 요청 중에만 표시 |
| `building_suggestion_list` | 추천 목록 | 검색창과 키보드 사이 | 예: `정보과학관`, 지원 여부, 보조 설명 | 결과 선택 시 목적지 후보 확정 |
| `building_search_empty` | 빈 결과 안내 | 목록 영역 | 결과 없음 및 검색 제안 | 결과가 없을 때 표시 |
| `building_search_keyboard` | 시스템 키보드 | 하단 | Android IME | 검색어 입력 및 검색 실행 |

### 6.3 추천 결과 표시 규칙

- 입력값 `정보`와 결과 `정보과학관`이 일치하면 결과의 `정보` 부분을 Primary 색상과 강조 굵기로 표시한다.
- 건물 공식명과 별칭을 검색 대상으로 사용한다.
- 지원 건물에는 `지원 건물`, 미지원 건물에는 `현재 AR 안내 미지원`을 표시한다.
- 동일 또는 유사한 명칭은 캠퍼스 내 위치나 건물 분류를 보조 텍스트로 표시한다.

### 6.4 주요 동작

1. 검색 입력창에 포커스를 두고 시스템 키보드를 표시한다.
2. 사용자가 입력하면 디바운스 후 Places 및 로컬 지원 건물 검색을 수행한다.
3. 검색 결과에 일치 키워드와 지원 상태를 표시한다.
4. 지원 건물 선택 시 다음 흐름을 결정한다.
   - 건물 자체가 목적지이면 경로 생성 또는 경로 미리보기로 이동한다.
   - 강의실 선택이 필요한 지원 건물이면 SCR-003으로 이동한다.
5. 미지원 결과 선택 시 안내 불가 사유와 대체 수단을 표시한다.

### 6.5 상태 정의

| 상태 | 화면 동작 |
|---|---|
| 입력 없음 | 최근 목적지 또는 추천 건물을 표시한다. |
| 입력 중 | 기존 결과를 유지하거나 지우고 검색 진행 상태를 표시한다. |
| 결과 있음 | 일치 키워드를 강조한 추천 목록을 표시한다. |
| 결과 없음 | `검색 결과가 없습니다`와 다른 키워드 입력 안내를 표시한다. |
| Places 사용 불가 | API 설정 필요 또는 외부 Google Maps 이동을 안내한다. |
| 네트워크 오류 | 입력값을 유지하고 `다시 시도`를 제공한다. |
| 미지원 건물 | 안내 시작을 비활성화하고 지원 범위 또는 외부 지도 이동을 제공한다. |

### 6.6 수용 기준

- 검색창, 추천 결과 및 시스템 키보드가 위에서 아래 순서로 표시된다.
- 입력 키워드와 일치하는 결과 문자열 부분이 강조된다.
- 지원 여부를 확인하기 전에는 AR 안내를 시작하지 않는다.
- 검색 실패 후에도 입력값이 유지되고 재시도할 수 있다.

## 7. SCR-003 강의실 선택

### 7.1 화면 개요

| 항목 | 내용 |
|---|---|
| 화면 ID | SCR-003 |
| 진입 조건 | 강의실 검색을 지원하는 건물 선택 |
| 주요 목적 | 선택한 건물 내부의 강의실명 또는 호수를 검색한다. |
| 종료 조건 | 강의실 선택, 건물 검색으로 복귀 또는 검색 취소 |
| 관련 요구사항 | FR-002, FR-003, FR-004, FR-102, FR-406 |

### 7.2 화면 구성

| UI ID | 요소 | 위치 | 표시 내용 | 동작 |
|---|---|---|---|---|
| `room_search_back` | 뒤로 가기 | 상단 좌측 | 뒤로가기 아이콘 | SCR-002로 복귀 |
| `room_building_title` | 선택 건물명 | 상단 | 예: `정보과학관` | 현재 검색 범위 확인 |
| `room_search_input` | 강의실 검색창 | 건물명 아래 | `강의실/호수 검색` | 호수 또는 강의실명 입력 |
| `room_suggestion_list` | 추천 목록 | 검색창과 키보드 사이 | `301호`, `302호`, 층 정보 | 선택 시 목적지 후보 확정 |
| `room_selection_state` | 선택 강조 | 목록 항목 | Primary Container 배경 | 현재 선택한 강의실 표시 |
| `room_search_keyboard` | 시스템 키보드 | 하단 | Android IME | 검색어 입력 및 검색 실행 |

### 7.3 표시 규칙

- 강의실 번호와 건물·층 정보를 함께 표시한다.
- 동일 강의실명이 여러 층 또는 건물에 존재할 경우 건물명과 층으로 구분한다.
- 지원하지 않는 강의실은 미지원 사유를 표시하고 선택 후 안내 시작을 제한한다.
- 선택한 강의실과 연결 가능한 권장 출입구가 없으면 경로 없음 상태를 표시한다.

### 7.4 주요 동작

1. 진입 시 선택한 건물의 추천 또는 최근 강의실을 표시한다.
2. 입력값으로 강의실 번호, 공식명과 별칭을 필터링한다.
3. 결과 선택 시 건물, 층, 목적지 노드와 권장 출입구를 검증한다.
4. 유효한 강의실이면 실외 및 실내 연결 경로 생성 단계로 이동한다.
5. 뒤로 가기 시 선택 건물 상태를 해제하고 SCR-002로 복귀한다.

### 7.5 상태 정의

| 상태 | 화면 동작 |
|---|---|
| 입력 없음 | 추천 강의실 목록을 표시한다. |
| 결과 있음 | 강의실 번호, 건물과 층을 표시한다. |
| 선택됨 | 선택 항목을 강조하고 경로 생성 동작을 활성화한다. |
| 결과 없음 | 검색어 수정 안내를 표시한다. |
| 데이터 다운로드 필요 | 실내 지도 다운로드 상태와 네트워크 요구사항을 표시한다. |
| 실내 데이터 없음 | 안내 불가 사유와 건물 출입구까지만 안내하는 대안을 제공한다. |
| 연결 경로 없음 | 대체 출입구 또는 다른 목적지 선택을 제안한다. |

### 7.6 수용 기준

- 선택한 건물명이 화면 상단에 표시된다.
- 강의실 번호와 층 정보로 목적지를 구분할 수 있다.
- 유효한 목적지만 경로 생성 단계로 전달된다.
- 경로가 없는 강의실에 AR 화살표가 표시되지 않는다.

## 12. Android 구현 매핑

현재 `outdoor_navi` 구조를 기준으로 다음과 같이 화면을 매핑한다.

실외 앱은 `indoor_navi`의 화면 스타일에 맞춰 배경 `#F7FAF8`, 흰색 카드, 주요 버튼 `#176C58`, 본문 `#152C27`을 사용한다. 카드 모서리는 16dp, 버튼 모서리는 12dp이며 터치 높이는 48dp 이상이다. AR 화면 상단은 반투명 어두운 초록색 패널과 흰색 글자를 사용한다. 지도·검색·안내 동작은 기존 실외 흐름을 유지한다.

| 화면/기능 | 현재 구현 위치 | 구현 시 주의사항 |
|---|---|---|
| SCR-001, SCR-002 | `ui/map/MapFragment`, `fragment_map.xml` | 지도와 검색 상태를 단일 UI 상태로 관리한다. |
| 목적지 카드 | `ui/map/DestinationCardView`, `view_destination_card_content.xml` | 후보, 경로 로딩, 성공, 오류 상태를 구분한다. |
| SCR-004 | `ui/ar/ArNavigationFragment`, `fragment_ar_navigation.xml` | 렌더링 상태와 화면 동작을 분리한다. |
| AR 화살표 | `ui/ar/ArrowOverlayView` | 저신뢰 또는 추적 손실 시 반드시 숨긴다. |
| 검색 로직 | `ui/map/PlaceSearchController` | 디바운스, 취소와 최신 요청 우선 처리를 유지한다. |
| 전체 UI 상태 | `navigation/NavigationViewModel` | 화면 회전 및 프로세스 재생성을 고려한다. |

SCR-003과 SCR-005는 현재 P0 PoC에 독립 화면이 없으므로 구현 시 별도 Fragment, DialogFragment, BottomSheet 또는 단일 화면 내 상태 전환 중 하나를 결정해야 한다. SCR-005는 기존 AR 상태를 유지해야 하므로 전체 Fragment 교체보다 오버레이 또는 BottomSheet 방식이 권장된다.

## 13. QA 체크리스트

### 13.1 공통

- [ ] 화면 회전 또는 프로세스 재생성 후 검색어와 목적지 상태가 복원된다.

- [ ] 검색창, 추천 결과와 키보드가 겹치지 않는다.

- [ ] 미지원 건물과 강의실에서 안내 시작이 제한된다.

### 13.3 AR 안내

- [ ] 좌측 하단에 경로 취소, 우측 하단에 검색 버튼이 표시된다.

- [ ] 검색 화면 진입 후 기존 경로가 유지된다.
- [ ] 경로 변경 취소 시 기존 웨이포인트와 진행 상태가 복원된다.
- [ ] 안내 종료 후 카메라와 위치 업데이트가 중지된다.

2. 경로 미리보기 화면에서 AR 안내 시작 전에 표시할 필수 정보와 확인 동작을 확정한다.
3. SCR-005를 BottomSheet, 전체 화면 Dialog 또는 Fragment 오버레이 중 어떤 방식으로 구현할지 확정한다.
4. 검색 결과에 표시할 최근 목적지 저장 기간과 개인정보 정책을 확정한다.
5. 위치·방향 신뢰도 등급과 AR 화살표 표시 임계값을 파일럿 실측 후 확정한다.
6. 강의실 데이터가 없는 건물에서 건물 출입구까지만 안내하는 대체 흐름을 확정한다.
