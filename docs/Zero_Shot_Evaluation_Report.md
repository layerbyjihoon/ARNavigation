## 2. 평가 대상

### 2.1 ResNet18-Places365

- 입력: 224×224 RGB, ImageNet 정규화
- 출력: Places365 장면 클래스 Top-3와 신뢰도
- 검토할 활용 방식: 계단실·복도·로비 등 장면 문맥 추정, 잘못된 위치 후보 필터링
- 주의점: 장면 분류 결과는 고유한 Landmark ID나 절대 위치가 아니므로 단독으로 FR-202를
  충족하지 않는다.

### 2.2 YOLO26n-seg Doorway Detection

- 입력: 640×640 RGB letterbox
- 표시 클래스: `doorway`, `door`, `people`, `window`
- 내부 클래스: `mirror` — 반사 영역의 구조물 오탐 억제에만 사용
- 기본 표시 임계값: 0.35
- 검토할 활용 방식: 출입구·문·창문의 공간 후보 검출, Landmark 탐색 영역 제한
- 주의점: 클래스 검출만으로 특정 문이나 출입구의 고유 ID를 결정할 수 없으므로 메타데이터 또는
  별도 식별 모델과의 결합이 필요하다.

### 3.1 성능 표시 해석 시 주의사항

- 화면의 모델 FPS는 최근 **모델 추론 지연시간**의 지수 이동 평균으로 계산한 처리량 추정치다.
- 두 모델은 하나의 직렬 실행기에서 순서대로 실행되므로 동시 실행 시 실제 결과 갱신 주기는 두
  모델 지연시간의 합에 가깝다.
- Camera FPS는 프레임 분석 파이프라인의 관측값이며 PRD의 최종 AR 렌더링 FPS와 동일하지 않다.
- 모델을 끈 직후 화면에 남은 latency/FPS는 이전 결과일 수 있으므로 비활성 상태의 수치를
  비교 자료로 사용하지 않는다.

### 4.2 공통 판정 척도

| 등급 | 정의 |
|---|---|
| A — 양호 | 기대 결과가 지속적으로 나타나며 내비게이션 입력 후보로 바로 검토 가능 |
| B — 조건부 | 대체로 유효하지만 특정 시점·거리·조명 또는 임계값 조건이 필요 |
| C — 미흡 | 일부 유효한 결과가 있으나 변동·오탐·미탐 때문에 보조 신호로만 사용 가능 |
| D — 부적합 | 출력이 장면과 반복적으로 불일치하거나 안전한 의사결정에 사용하기 어려움 |
| N/A | 해당 장면에서 평가하지 않았거나 증거가 부족함 |

신뢰도가 높다는 이유만으로 A를 부여하지 않는다. **정답 의미, 시간적 지속성, 실패 시 위험**을
함께 고려한다.
